Layout Explorer

Almost every website is built from the same four parts: a header, the main content, some asides (stuff on the side), and a footer. A layout is where those parts go.

Every page on this site shows the same coffee shop website built a different way. Use the Layouts and Styles menus at the top to look through them.

  1. 1Pick a page from the Layouts or Styles menu.
  2. 2Switch between Phone, Tablet, and Desktop.
  3. 3Turn on Make it responsive and watch the media queries fix the layout.

Screen Sizes and Media Queries

Every example on this site is built mobile first: write the phone layout first with no media query, then add min-width media queries as the screen gets bigger. Get used to these sizes. You will write them yourself soon.

ScreenWidthMedia queryCommon layout
Phoneup to 599pxNone. This is your base CSS.1 column
Tablet600px and up@media (min-width: 600px)2 columns
Desktop1024px and up@media (min-width: 1024px)2 or 3 columns
